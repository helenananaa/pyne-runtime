# 官方差异评估与持续 Goal

2026-09-30，本 Goal 的验收条件是：必须有可复现、覆盖已声明支持范围的独立
官方对照手段，能说明覆盖分母、差异率、边界和实际影响，才能判断项目与官方
差别已经很小。没有此证明就保持 Goal active。当前结论为 **尚未证明，继续启用**。

当前评估JSON为 `pyne.official-alignment-assessment/2`：有限数保留JSON number，
非有限数用 `nonfiniteNumber` 对象明确保留，缺失用null。导出禁止非标准
Infinity/NaN常量；不得把非有限输出改成缺失来隐藏差异。报告格式版本独立于
包版本、计算语义和快照格式，历史schema-1收据不改写。

## 可复现评估

```powershell
python scripts/official_alignment_report.py --output .tmp/official-alignment.json
python scripts/official_alignment_report.py --require-small-difference
python -m pytest tests/test_official_alignment_report.py -q
```

第一条是诊断报告，不是验收通过。第二条目前退出码为 1：缺少全范围证明时关闭
验收入口。报告保留每列每个不同单元的官方值、Pyne 值及索引，也列出没有映射的
输出列、工作负载和模式。Pine 输入列与独立公式控制列单独列出，不计作运行时输出。

所有已注册采集都检查 Pine 源码、原始 Pine Logs 的 SHA256、行完整性，以及 JSON
解析结果与原始日志的一致性。原始官方值不能从 Pyne 结果生成或覆盖。动态 plot
名称取实际执行结果；启动区间和以往专项测试的 reference-only 列都计入差异。
双方都缺失的单元单列，不能增加有效单元的一致率。

## 新发现及影响

Chrome 上新增 `conditions_pivot` 的 48 行以及 `pivot_isolated_confirmation` 的
32 行原生 Pine v6 输出，保留 `.pine` / `.tradingview.txt` / `.tradingview.json`。
两份批量映射分别有 42 和 98 个差异，已经计入上述分子。

- **Pivot 重复极值**：原生重复峰值确认右侧较晚的峰；当前 Pyne 要求窗口中唯一
  极值，因此会漏掉合法信号。原生 right=0 的平坦序列在满足左侧长度后持续输出，
  当前 Pyne 也会遗漏。需要统一批量和增量规则，并保留因果确认时机。
- **Pivot 缺失边界**：独立样本中，原生比较在左右邻近 NaN 处停止；Pyne 目前忽略
  整个窗口中的 NaN，仍让缺失值另一侧的极值影响结果，因此可能漏信号。
- **Pivot 启动**：原生数据集起点要求完整左右跨度。Pyne 可用历史起步会提前出现
  极值；旧图表窗口采集不能替代数据集起点证明。该差异已计入，不改写旧采集值。
- **Rising 缺失输入**：普通输入的原生 rising 与连续严格上涨公式一致，独立
  “高于过去最高值”公式则不一致。缺失输入中原生保留部分 true 信号，Pyne 给出
  false；还需独立控制样本确定传播规则，不能直接把推测写成运行时语义。

启动区间、原生缺失 percentile 排序、原生高偏移方差消减、原生缺失/平坦
correlation 与稳定 Pearson 的差异也都计入。既有 58 个 capture-family 零差异
结论仍是固定专项的结论，不能取代此全范围验收。

## 百分位数缺失排序反证与范围扩展（语义 10，未修改计算实现）
