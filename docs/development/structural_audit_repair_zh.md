# 非数值兼容问题修复记录

候选版本为 `0.4.1rc35`，计算语义为 `40`。本轮处理前一轮只读审计
复现的 5 项正确性问题和 4 类性能、资源问题。修复属于独立 Python 包，
供应商数据获取和宿主生命周期仍由调用方负责。

| 问题 | 修复与回归边界 |
| --- | --- |
| 低周期重复时间戳丢行 | 缓存按时间戳保留完整行组；同样 5 行恢复为 `[3,2]` 分组数量。无最终性承诺时刷新范围，能看到后来新增的同时间戳行。 |
| 非法 OHLCV 污染缓存 | 完整响应通过结构及数值有效性校验后才发布缓存；脚本捕获异常后，供应商修复输入，原健康会话能够恢复请求。 |
| 失败恢复覆盖健康状态 | 恢复形状、复制、函数状态和预算检查在采用状态前完成；新会话准备失败也回滚会话拥有的状态与缓存。已有预览和后续计算保持。 |
| 旧引用释放误删新实例 | `release(key, shared=lease)` 按实例归还；旧的按 key 归还方式在替换期间保守计数，平衡归还后清账。 |
| 重复 seed 导致回放不一致 | 初始化只允许一次，包括 `seed([])`；已初始化会话再次 seed 在改变状态前拒绝。重播替换历史应创建新会话。 |
| 请求重复复制完整历史 | 符合安全快路径的字面字段名、字段元组和当前低周期分组使用索引投影，省去完整历史上下文；`time_close`、特殊 NumPy 错误策略及极值输入仍保守回退。任意 Python thunk 仍每次执行，并保留上下文身份、变异共享和派生缓存时机。 |
| 合法共享集合校验指数展开 | 单次操作复用访问结果，循环路径与完成节点分开；深度取最长路径，保留共享引用，变异后重新验证。 |
| 输入和矩阵限额在物化后检查 | CSV、生成器和矩阵在首次超限时停止；既有数据及 DataFrame 在复制前检查。CLI 保留执行失败退出码和 JSON 格式。 |
| 增量 Pivot 逐条复制窗口 | 使用按缺失值分段的单调候选队列，保留左右不对称相等值判断、预热及确认延迟；算法提取到独立内部模块。 |
