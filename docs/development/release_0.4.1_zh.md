# 0.4.1 发布收尾

日期：2026-10-06。目标包版本 0.4.1，计算语义 42。

## 唯一近期里程碑

将已经验收的计算包正式交付。本轮冻结功能，不新增 API，不启动全仓审计。
源码基线为 `ef4f9dbc502133ebf3ccc2baa19ee3e27f4534b6`；发布准备只修改
版本元数据、升级说明、路线图、验收记录和必要的发布验收基础设施。
生产源码保持冻结。旧执行计划是历史背景，不自动
生成本轮任务。

三条产品流程为 CSV 指标计算、历史策略研究、历史初始化到实时更新和
重启恢复。包级验收使用独立安装的 wheel 和宿主无关数据；具体宿主的
数据、图表和采用验收由适配仓库负责。

## 升级要求

- 0.4.0 的计算语义为 5，0.4.1 为 42。旧语义的 local/state/replay
  快照必须从权威 OHLCV 重建，不修改快照版本数字绕过拒绝。
- 保存原始脚本、参数、数据和所需 provider；先重算代表性指标与策略，
  确认结果修正符合使用需求，再切换持久化状态。保留旧版本和原始数据
  作为回退依据；新版状态不能假定可由旧版直接读取。
- rc37 /42 的真实快照与本轮运行时兼容，恢复仍检查脚本、参数、格式和
  所选资源预算。计算身份、包版本、schema 版本各自独立。
- 浮点数学库的跨平台差异可能改变 `exp()` 等计算的最后一位。本轮以
  同平台真实 rc37 wheel 为独立参考，严格比较旧版与新版恢复、preview
  和续算，不放宽容差。跨平台/数学库切换应重算验证代表性工作流，不能
  将计算语义相同解读为所有数学库之间逐位一致。
- 默认仍为调用进程中的完整 Python，计算预算 `None` 表示无限；宿主
  显式选择隔离、权限和资源策略。
- 性能记录针对确定负载。ALMA 的约 9.5–23.4 倍收益为极端跨度卷积核心，
  不代表完整脚本端到端收益；40k 样例进程峰值内存增加约 10–12 MiB。

## 发布退出条件

1. 当前版本完整本地质量门禁通过，生产源码与冻结基线保持一致。
2. main CI 和同一构建 wheel 的三系统 × Python 3.11/3.12/3.13 安装
   门禁通过。标签必须匹配包版本，并指向 main 中的已验收提交。
3. 发布流程完成，公开 wheel、sdist 与 SHA256SUMS 下载后校验一致，
   公开 wheel 在隔离环境完成独立工作流验收。
4. 验证公开资产后才更新 `published-version` 和 README 安装入口。

满足条件即结束本轮。只修安装失败、声明契约错误、错误计算/状态破坏和
目标负载不可接受的性能问题；代码美化、冷门 API 和非阻断优化进入后续
待办。失败记录保留，针对失败项复验，不默认重新开始全仓扫描。

## 首次跨平台验收阻断与处理

首次 main CI 为 `37460790292`，日志保留，未直接重跑掩盖失败。
Windows checkout 的自动换行转换改变原始 CSV 和 legacy baseline 的
字节身份；本地与 Git 原始 blob 的哈希正确。通过 `.gitattributes` 对
这些证据禁用换行转换，保留原始文件、SHA 和容差，并新增真实 Git
`autocrlf=true/false` checkout 回归。

Linux/macOS 的两项续算捕获比较揭示 Windows 保存的少数 ALMA 数值与
本机数学库相差一个尾数位。原始 Windows 捕获及哈希不变；纳入真实且
SHA 核验的 rc37 wheel，子进程在每个平台运行旧版，严格对照完整新旧
结果；原捕获的 Windows Python 3.12 环境继续逐位匹配原始结果。
第二次 CI 的 Windows Python 3.11 也显示相同的尾数差异，因此捕获环境
判据收窄到原始 Python ABI，不能仅按操作系统判断。未修改任何生产实现、数值参考
捕获或比较容差。这是发布验收参考的修正，不是计算语义变更。

## 发布后的开发方向

可验收的需求，优先脚本诊断、实际负载表现与通用集成契约。
不为了追求零缺陷或 API 数量继续扩大这一版。
